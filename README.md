# PS026-Healthcare-System
---

# 🧩 Microservices

### Patient Service
Manages patient records and provides CRUD operations for patient information.

### Appointment Service
Manages doctor appointments and consultation scheduling.

### Billing Service
Manages patient billing and payment-related information.

### Auth Service
Handles user authentication and JWT token generation.

### API Gateway
Provides a single entry point for client requests and routes requests to the appropriate microservice.

### Eureka Server
Provides service registration and discovery for the microservices.

# 🚀 Project Goal

The goal of this project is to demonstrate a scalable healthcare management platform using a microservices architecture, with independent services for patients, appointments, billing, authentication, service discovery, and API routing.
